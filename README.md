# Data Wrangling — Notebook Workspace

**Public repository · Learning / practice workspace**

## Focus
This repository is intended for notes and exercises about preparing data for analysis: inspecting datasets, cleaning inconsistent values, transforming columns, and making analysis reproducible.

## Current status
At the time of this README update, the repository contains **documentation only**. No notebook, dataset, completed analysis, performance result, or demonstrated production workflow is claimed yet.

## When exercises are added
Document the dataset's origin and license, the question being explored, the transformation steps, how to reproduce the notebook, and a short summary of observed results. Use synthetic or explicitly shareable data; never upload customer records, credentials, or company data.
